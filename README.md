📊 Bluestock MF Analytics Platform
*End-to-End Mutual Fund Data Engineering, Advanced Risk Analytics & Executive Dashboard*


📌 Project Overview
The **Bluestock MF Analytics Platform** ingests data from AMFI India, mfapi.in, and NSE/BSE to deliver full-stack mutual fund analytics. It covers data ingestion, star-schema database design, EDA, risk-adjusted performance calculation (Sharpe, Sortino, Alpha, Beta, VaR), and interactive Power BI dashboards.


🛠️ Tech Stack & Tools
* **Language:** Python 3.x
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Plotly, SQLAlchemy
* **Database:** SQLite3 / PostgreSQL (Star Schema)
* **Visualization:** Power BI Desktop / Tableau
* **Environment:** Jupyter Notebook, VS Code, Git
